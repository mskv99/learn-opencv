# Компьютерное зрение в вычислительной фотолитографии
В этом репозитории содержатся материалы лекций и семинаров про применению методов компьютерного зрения в вычислиетельной фотолитографии.
в рамках курса `"Современные методы матетического моделирования"`. Идея курса – рассмотрение некоторых задач из области вычислительной фотолитографии, которые могут быть решены с помощью данных CV-методов. 


## План занятий
Ниже представлен план занятий:

* **Лекция 0:** Основные методы обработки изображений и их практическое применение. 
* **Лекция 1:** Применение глубокого обучения с вычислительной фотолитографии.
* **Лекция 2:** Классификация изображений с CNN.
* **Лекция 3:** Рекуррентные нейронные сети.
* **Лекция 4:** Механизм внимания и трансформеры.
* **Лекция 5:** Детекция и сегментация объектов.
* **Лекция 6:** Генеративные модели.
